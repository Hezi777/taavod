## Cross-screen coverage and manual checks

- The app exposes ⌘K search and ⌘-number route shortcuts; practice exposes ⌘Return. Several dialogs use the standard Escape/cancel action. This does not establish complete keyboard or VoiceOver coverage.
- Reduce Motion is handled for dashboard/card interaction, Coach scrolling, practice hints, and mascot motion. The active portrait is video based. Its timer stops after seeking settles and when the app window is inactive; Low Power Mode reduces updates to 30 Hz. SceneKit remains development artwork.
- The portrait uses a static poster until its cursor-scrub video is ready. Scrubbing is bounded to the app window, throttled and smoothed, and runs at a lower update rate in Low Power Mode. Parent observed different portrait frames after pointer changes and verified the floating portrait still opens Coach. Exact gaze is limited by the mixed directions in the supplied footage.
- GUI reviewed: dashboard dark, learning overview/path/reader dark, practice dark, schema explorer, Jobs/Portfolio/Interviews light, project detail, Settings light/dark, provider setup, and floating Coach. Checked ⌘K search, exact second-lesson landing, exercise-to-practice landing, and Escape dismissal. Learning grid reflowed to two columns at the smaller window size.
- GUI review caught and fixed the schema segmented-label wrapping, course buttons exposing a progress-indicator role, disabled Save styling, job-title hierarchy, and a new-role location value being overwritten, schema presentation before selecting an exercise, and switching back from empty Results.
- Hover borders use 140 ms easing; press feedback uses 120 ms opacity/scale. Disabled controls suppress interactive-card cursor/tint; Reduce Motion removes scale/interpolation. CUA exposes clicks/drags but no hover-only mouse movement, so these timing/hover details were reviewed in source, not certified by interactive latency measurement.
- Not manually covered in this pass: full VoiceOver/keyboard traversal, every screen at minimum width, larger text, live provider/search requests, runtime install/remove, file import/export, and macOS Reduce Motion/Low Power Mode toggles. Cursor normalization, reverse/axis behavior, frame-rate-independent response and lesson intent/draft preservation have automated tests.
